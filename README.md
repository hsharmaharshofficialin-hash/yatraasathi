# YatraSathi

**Go further. Feel closer.**

An honest travel companion for exploring India. This tree ships a Jaipur trip: UNESCO-cited narratives, Sanskar etiquette cards, a Claim Ledger (Pramaan), network-honest offline caching, and an SOS panel that will not pretend to dispatch 112.

```
yatrasathi/
├── README.md, DEPLOY.md, make_zips.py
├── src/                       Next.js 16 App Router frontend + /api fallback
├── public/                    images, service worker, on-device worker
├── yatrasathi-backend/        FastAPI + SQLAlchemy + Alembic
└── yatrasathi-frontend/       .env.example for the Vercel project
```

In this repository the Next.js app lives at the **root** so the preview can boot. Zip packaging still emits `yatrasathi-frontend.zip`. The Python API lives only in `yatrasathi-backend/`. The two sides **never import each other**; they talk over HTTP. `src/lib/api.ts` is the only frontend module that reads the wire format.

HTTP responses are serialized by Next.js and FastAPI. There are **no developer-edited JSON data files**. Seed data lives in Python modules (`yatrasathi-backend/src/data/jaipur_sites.py`) and JavaScript/TypeScript modules (`src/data/`). Locale strings live in `src/data/locales.ts`. The PWA manifest is generated by `src/app/manifest.ts`.

> This sandbox’s Next.js starter is TypeScript and `tsc` is part of delivery. Application seed/locale data is still code modules, not JSON. The companion API is Python.

## What works vs what is mocked

| Feature | Status |
| --- | --- |
| Pramaan cited-or-abstain + Claim Ledger | Works (rule-based retrieval over the verified pack). Live OpenAI only if `OPENAI_API_KEY` is set. |
| Sanskar cards + I'm here / ~150 m geofence | Works. Many etiquette fields are **unverified** on purpose. |
| Network-honest mode, SW cache, queued edits | Works. Offline answers use a Web Worker over the cached pack. |
| Arena Mode | Works. Without an LLM key the “plain” column is a **labelled simulation** of ungrounded tourist-guide claims, not a silent fake model. |
| On-device neural model (WebLLM) | **Not bundled** (size). Worker retrieval is labelled `On-device, offline`. |
| Bol Chaal, Bheed Barometer, Vichaar Ledger | Designed screens. GI registry rows are real checkable facts; licensed-guide and homestay rows are **mock**. Phrase “Unreviewed” tags are honest. |
| SOS | `tel:112`, on-device coordinates. No dispatch. |
| Overpass toilets/water/hospitals | Live OSM. If Overpass is silent, the UI says unknown — not “no toilets”. |
| Ratings / restaurant lists | Refused. Unknown is valid. |

## Architecture

```
Browser (Next.js, port 3000)
  ├─ src/lib/api.ts  ──HTTP──►  FastAPI (port 4000)   or  Next.js /api fallback
  ├─ service worker + IndexedDB (trip pack, queued edits)
  └─ public/workers/offline-engine.js  (on-device pack retrieval)
FastAPI
  ├─ Pramaan / retrieval / claim check / rule-based fallback / optional OpenAI
  └─ PostgreSQL (sites, sources, etiquette_facts, knowledge_facts, itineraries, changelog)
```

## Local run

**Frontend** (repo root):

```powershell
copy .env.example .env
npm install
npx drizzle-kit push
npm run dev
```

The Next.js `/api` routes seed the database if it is empty so the preview has the Jaipur pack. FastAPI never seeds on boot.

**Backend** (`yatrasathi-backend`):

```powershell
cd yatrasathi-backend
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy .env.example .env
python scripts\check_env.py
alembic upgrade head
python scripts\seed.py
uvicorn src.main:app --reload --host 0.0.0.0 --port 4000
```

Point the frontend at FastAPI by setting `NEXT_PUBLIC_API_URL=http://127.0.0.1:4000` **before** `npm run dev` / `npm run build` (Next inlines it at build time).

One helper script (does not leave servers running):

```powershell
py scripts\run_local.py
py scripts\run_local.py --apply
```

## Demo story

1. Open `/` — Jaipur trip + Trip Readiness. Cache maps, stories, cards, phrases.
2. Open Amer Fort or Jama Masjid and tap **I'm here** for a Sanskar card with sources and dates.
3. `/ask` — UNESCO questions yield a Claim Ledger. Tap a sentence for evidence.
4. Ask for restaurant ratings — the engine abstains.
5. `/arena` — plain vs Pramaan; unsupported sentences highlighted.
6. Airplane mode — banner **On-device, offline**; `/demo` still answers from the cached pack.

`/demo` has preset questions.
